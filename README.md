# React Mindmap Builder

This repo is a fully featured Mindmap Builder built with Visuallyjs React.

For a live demo see https://visuallyjs.com/demonstrations/mindmap

## Installation/Getting Started

1. Clone this repo
2. `npm install`
3. `npm run dev`
